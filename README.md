# DailyClear · 日清表

> 项目英文名 **DailyClear**，中文名「日清表」。

一个给班级用的「每日清」小站：**语数外物化生**六个区域，老师每天点一下就能填，
学生或教室大屏打开首页就能看到今天六科要清掉的内容；后台按日期翻看历史记录，
随时把本周（或任意日期范围）导出成 `.xls` 表格。

- 纯 PHP，**不需要登录**，**不需要装任何 PHP 扩展**（zip / mbstring 都不是必须的）
- 数据库二选一：**SQLite 单文件**（默认，传上去就能用）或 **MySQL**（改 6 行配置）
- 前台不自动刷新、不弹广告、没有多余组件：六个区域直接铺满第一屏，字随屏幕自动放大
- 导出的是 Excel 2003 XML 格式的 `.xls`，Excel / WPS / 手机版 Office 都能直接打开

## 快速开始

1. 把整个目录上传到网站根目录（PHP ≥ 7.4）。
2. 打开 `lib/` 目录，把 `config.sample.php` 复制一份改名成 `config.php`。
   - 想省事：什么都别改（默认用 SQLite），只要 `data/` 目录可写就行。
   - 想用 MySQL：把 `DB_DRIVER` 改成 `'mysql'`，填好 `DB_HOST / DB_PORT / DB_NAME / DB_USER / DB_PASS`。
3. 访问首页。第一次访问会自动建表，然后就能填了。

后台在 `/admin`（等价于 `/admin.php`）。导出本周在首页最下方，或直接访问 `/export.php`。

## 目录结构

```
index.php          客户界面（六科区域，直接铺满第一屏）
admin.php          后台（按日期看记录 + 导出）
admin/index.php    只是把 /admin 转发到 admin.php
api.php            填写 / 保存接口（返回 JSON，前端不刷新页面）
export.php         导出 xls
lib/config.sample.php  配置模板（复制成 config.php 后修改）
lib/bootstrap.php  时区、错误处理、公共小函数
lib/db.php         数据库连接 + 自动建表
lib/repo.php       数据读写、日期与周范围计算
lib/xls.php        生成 Excel 表格
lib/partials.php   公共页面片段（填写弹窗、数据注入）
assets/style.css   样式（含教室大屏自适应）
assets/app.js      前端交互（点卡片填写、保存、即时更新）
data/              SQLite 数据文件所在目录（用 MySQL 时是空的）
install.sql        MySQL 建表语句（程序会自动建表，一般不用手动执行）
```

## 配置说明（都在 `lib/config.php`）

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `DB_DRIVER` | `sqlite` | `sqlite` 单文件数据库；`mysql` 用 MySQL |
| `SQLITE_PATH` | `data/riqing.sqlite` | SQLite 数据文件位置，可以放到站点目录之外 |
| `DB_HOST` / `DB_PORT` / `DB_NAME` / `DB_USER` / `DB_PASS` | — | MySQL 连接信息 |
| `SITE_NAME` / `SITE_SUB` | `日清表` / 空 | 站点名和副标题（副标题可以写班级，例如「高二(3)班」） |
| `TIMEZONE` | `Asia/Shanghai` | 决定「今天是哪一天」，服务器在境外时一定要填对 |
| `DAY_ROLLOVER_HOUR` | `0` | 0 点换日；设成 `4` 就是「凌晨 4 点前算前一天」，熬夜补填不会跳到第二天 |
| `SUBJECTS` | 语文 数学 英语 物理 化学 生物 | **增删科目只改这里**，界面和大屏配色会自动适配；只想临时换个排列顺序的话不用动它，后台当天换一下就行（第二天自动恢复） |
| `MAX_CONTENT_LEN` | `2000` | 每科每天最多多少字 |
| `ADMIN_PASSWORD` | 空 | 目前只是占位，还没有实现登录逻辑 |

数据表只有一张 `riqing_records`（`record_date` + `subject` 唯一，即「一科一天一条」），
历史记录永久保留；把内容清空保存 = 删除那一条，不会删表。
另有一张 `riqing_settings`（键值对）只存主页卡片顺序这类小设置，删掉里面的行就等于恢复默认。

## 怎么用

**老师填写**：打开首页 → 往下滑到底 →「我要填写」→ 选科目 → 写内容 → 保存。
也可以直接点某一张科目卡片（点卡片就是改这一科）；内容清空保存即删除该条记录。
`Ctrl / ⌘ + Enter` 等于点保存。

**清空有二次确认（防误删）**：弹窗里点「清空」不会马上删，按钮先变成「确认清空（3）」并灰掉、
下面出现红字「清空后不可恢复」，**等 3 秒**倒计时结束才能再点一次确认；
这 3 秒里打字、换科目、按 Esc、点取消都会自动撤掉这次确认。

**学生 / 教室大屏**：打开首页就行。六科内容铺满第一屏，字随屏幕自动放大（1080P、2K、4K、4:3 的老投影都适配）；
排成「三列两行」，右上角可以手动切成「三列」或「单列」（见下一节）；
页面**不会自动刷新**，需要更新时按一下浏览器刷新即可。

**后台**：`/admin`，左边日历点哪天看哪天（有记录的日期会标「N 科」），右边能直接改；
导出支持「本周 / 这一天 / 任意日期范围」，也可以只导「明细」（逐条记录）。

**临时调整主页卡片顺序**：后台 →「主页卡片顺序」→ 想让哪一科排到前面，就在它那一行选「和 某某 调换」，
可以连着换好几处，换完点「保存顺序」才生效（主页六科区域、导出周表的行顺序都会跟着变；
科目配色固定跟着科目走，怎么换都不会乱）。
顺序 **只对今天生效，第二天打开自动恢复默认**；想马上恢复就点「恢复默认顺序」。
存的时候连「哪天调的」一起写进 `riqing_settings`，过了这一天就自动不用了，配置文件不用动。

## 屏幕适配（投影仪 / 教室大屏）

首页六张卡片按屏幕**自动**排版：

| 屏幕 | 排法 |
| --- | --- |
| 手机竖屏（宽 < 700px） | 单列，一科一段往下滑 |
| 平板 / 小窗口 | 两列三行 |
| 宽屏（宽 ≥ 1080px） | 三列两行 |
| **4:3 / 5:4 的老投影**（1024×768、1280×960、1280×1024、1600×1200…） | **三列两行**，并且把第一屏撑满 |

4:3 这类屏宽度常常不到 1080px，光看宽度会掉成「两列三行」；所以样式里额外按**屏幕比例**判断了一次（宽高比落在 5:4 ~ 3:2 之间就按三列处理）。

如果自动排出来还是不合心意（比如投影仪的分辨率特殊、或者你想在电脑上直接看单列），
点首页**右上角**的「自动 / 三列 / 单列」切换器就行：

- 选一次会记在**这台设备的浏览器里**（`localStorage` 的 `rq.layout`），以后打开还是这个排法；
- 换一台电脑 / 换浏览器要重新点一次；点「自动」就清掉记忆、回到按屏幕判断；
- 手机上不显示这个切换器（那里只有单列有意义）。

另外，**「我要填写」和「导出本周」永远在页面最下方**（第一屏之下），大屏展示时不会挡内容、也不会误点。

### 字太小 / 太大：左上角「字体 － ＋」

顶栏左上角有个字号调节器（标签「字体」，右边两个键 `－` `＋`），点一下整站字号变一档：

- 共 6 档：**85% / 100% / 115% / 130% / 145% / 160%**（100% 是默认值，1024 宽的投影上约等于 16.5px）；
- 改的是浏览器根字号，卡片、正文、日期、弹窗**全都跟着放大**，不是只放大某一处；
- 同样**记在这台设备的浏览器里**（`localStorage` 的 `rq.fs`），刷新、第二天打开都还是这个字号；
- 调到两头时对应的键会变灰；手机上不显示这个调节器（那里用系统字号 / 浏览器缩放就行）。

教室后排看不清就按两下 `＋`；如果放太大导致要滚动，点 `－` 退回来。和右上角的布局切换器互不影响，可以自由组合。

## 导出说明

- 导出的 `.xls` 是 **Excel 2003 XML** 格式：服务器不需要装 zip / mbstring 之类任何扩展，
  Excel、WPS、手机版 Office 都能直接打开。
- 「周表」：**行 = 科目，列 = 周一 ~ 周日**，格子里是当天的内容，横向打印、自动换行、六科配色。
- 第二个工作表「明细」：按日期逐条列出（日期 / 星期 / 科目 / 内容 / 更新时间）。
- 如果 Excel 弹「文件格式与扩展名不一致」，点「是」就能打开。
- 一次导出超过 62 天会自动截断，表格里会注明实际范围。

## 安全提示（重要）

**前台和后台都没有登录密码**：任何拿到网址的人都能填写、查看、导出。
日清表内容本来就是给学生看的，通常没问题；但如果不希望陌生人乱填，建议：

- 把后台和填写接口放到校内网 / 加一层反向代理的 Basic Auth；
- 或者自己加一个登录页（`ADMIN_PASSWORD` 常量已经预留）。

另外请务必确认 `lib/config.php` 不会被下载（本仓库用 `.gitignore` 忽略了它；
Apache 下也可以给 `lib/` 加一条 `Require all denied`，本程序的所有 `lib/*.php` 都只被 `require`，不需要直接访问）。

## 常见问题

- **首页报错 / 空白**：先看 `lib/config.php` 是否已创建、数据库配置是否正确；
  具体错误不会显示给访客（只写进服务器错误日志）。
- **提示「缺少配置文件」**：忘了把 `lib/config.sample.php` 复制成 `lib/config.php`。
- **日期不对**：改 `TIMEZONE`（服务器在境外时尤其要注意）。
- **晚上熬夜补填，希望算前一天**：把 `DAY_ROLLOVER_HOUR` 设成 `4`。
- **内容里的换行**：会原样保留；`< > &` 等字符会自动转义，不会被当成代码执行。
- **每天自动换新的一天**：0 点后打开首页就是新的一天，昨天的内容不会丢，后台随时能翻回去看。
- **投影仪打开是两列三行**：4:3 / 5:4 已经自动适配成三列两行；如果投影仪被缩放成别的比例，点右上角切换器选「三列」。
- **想加科目 / 删科目**：只改 `lib/config.php` 里的 `SUBJECTS`，卡片数量和大屏布局会自动跟着变。
- **手滑点了「清空」**：第一下只是进入确认状态（红字提示 + 3 秒倒计时），这时关掉弹窗、打字、换科目都会自动撤销，
  什么都不影响；只有倒计时结束后再点一次「确认清空」才真的删除，删了不可恢复。
- **教室后排看不清**：点顶栏左上角「字体 ＋」，整站字号最大能放大到 160%。
